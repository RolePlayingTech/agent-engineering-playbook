# Workflows

- [Research to skill](research-to-skill.md): source intake, evidence appraisal, evaluation, draft, review and maintenance

## Issue to pull request
Read repo rules -> verify issue still exists -> define acceptance -> implement on branch -> focused checks -> diff review -> PR with evidence -> independent review -> authorized merge. Deployment is a separate action.

## Parallel development
Identify independent tasks -> assign nonoverlapping ownership -> run isolated workers -> collect handoffs -> integrator checks overlap and tests -> review -> merge with permission.

## Regression learning
Observe failure -> create reproducible case -> add behavioral evaluation -> adjust guidance -> rerun baseline and new case -> document results.

## Long-running session
Record objective, state, commits, blockers, tests and next action. On restart verify checkpoint against actual files.
