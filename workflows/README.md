# Workflows

## Research to skill
Discover primary source -> source-triage -> extract a bounded claim -> design a small experiment -> evaluate -> draft SKILL.md -> independent review -> adopt with an expiry/revisit condition.

## Issue to pull request
Read repo rules -> verify issue still exists -> define acceptance -> implement on branch -> focused checks -> diff review -> PR with evidence -> independent review -> authorized merge. Deployment is a separate action.

## Parallel development
Identify independent tasks -> assign nonoverlapping ownership -> run isolated workers -> collect structured handoffs -> integrator checks overlap and tests -> review -> merge with permission.

## Regression learning
Observe failure -> create reproducible case -> add behavioral evaluation -> adjust instruction/tooling -> rerun baseline and new case -> document results.

## Long-running session
Record checkpoint with objective, state, commits, blockers, tests and next action; on restart re-read repository and verify checkpoint against actual files before continuing.
