# Skills

Each skill lives in `skills/<name>/SKILL.md` with YAML `name` and `description`. See [Skill specification](SPECIFICATION.md) for the repository's minimal contract and review checklist. Load procedures only when relevant; a skill does not grant additional permissions.

| Skill | Trigger |
| --- | --- |
| [source-triage](source-triage/SKILL.md) | Evaluate a source before turning a claim into guidance |
| [bounded-implementation](bounded-implementation/SKILL.md) | Implement a narrowly scoped issue |
| [independent-code-review](independent-code-review/SKILL.md) | Review actual code changes independently |
| [behavioral-evaluation](behavioral-evaluation/SKILL.md) | Assess observable agent behavior |
| [parallel-handoff](parallel-handoff/SKILL.md) | Coordinate independent agent work |
| [context-budgeting](context-budgeting/SKILL.md) | Resume or compress a long-running session |

These skills have **not** been empirically validated in this repository. Use only what is relevant; avoid stacking overlapping instructions.
