# Source triage
1. Record original URL, author, publication date, access date and source type.
2. Extract specific claims and distinguish observed measurements from opinion or vendor promotion.
3. Identify the environment, model, sample size and limitations; mark missing details unknown.
4. Compare with another independent source when practical.
5. Propose a minimal reproducible experiment and a failure condition.
6. Classify as **tested locally**, **primary-source recommendation**, **third-party observation**, or **hypothesis**.
7. Publish a short synthesis in research/, link sources and avoid copying substantial text.

Output: claim, evidence, confidence, applicability, test, rollback/expiry trigger.
