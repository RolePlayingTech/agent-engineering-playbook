# Bounded implementation
1. Read AGENTS.md, issue and touched code. Check existing branches/PRs.
2. State scope, out-of-scope and acceptance criteria in 3-6 lines.
3. Make the smallest maintainable patch; do not opportunistically refactor.
4. Run available focused validation proportional to the risk; do not wait for disabled CI.
5. Inspect diff and record exact evidence.
6. Handoff with changed files, checks run, unresolved issues and review notes.

Stop on missing authorization, conflicting work, security-sensitive uncertainty or requirements that cannot be inferred safely.
