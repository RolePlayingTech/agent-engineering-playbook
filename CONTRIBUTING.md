# Contributing

Prefer small, source-linked changes. Each research-derived recommendation must include original URL, author/publisher, publication and review dates, applicability, limitations, evidence classification and a practical test proposal.

Do not present vendor marketing, single anecdotes or benchmarks as universally proven. Attribute ideas and paraphrase instead of reproducing articles. Keep SKILL.md concise and actionable. Propose a skill only when a repeated task needs a reusable procedure; otherwise add a note to research/.

Avoid duplicating existing skills. Use PR review for changes to shared AGENTS.md. No secrets, unsafe commands, or automatic deployments in examples. Revisit time-sensitive guidance regularly.
